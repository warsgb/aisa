## 使用示例

### 在Skill中使用

```markdown
# 金融行业客户深度研究

## 引用框架
@include shared-frameworks/search/baidu-web-search.md

## 客户基础搜索
# @baidu-search:background("{{customer_name}}", "finance")
# @baidu-search:decision("{{customer_name}}", "finance")
# @baidu-search:cooperation("{{customer_name}}")

## 招投标信息搜索
# @baidu-search:bidding("{{customer_name}}")

## 生成报告

基于搜索结果，生成包含以下内容的报告：

### 客户背景
@search-result:background

### 决策链分析
@search-result:decision

### 历史合作
@search-result:cooperation

### 招投标情况
@search-result:bidding

### 采购分析
基于招投标信息，分析客户的：
1. 采购偏好（自主采购 vs 集成采购）
2. 采购周期（年度/季度/项目制）
3. 竞争对手（已中标的其他厂商）
4. 市场切入点（未覆盖的产品线）
```

### 动态参数

支持使用变量：

```markdown
# @baidu-search:bidding("{{customer_name}}")
# @baidu-search:bidding("{{customer_name}} {{department}}")
```

## 招投标信息分析维度

### 1. 采购偏好分析

**分析维度**：
- 采购方式：公开招标 vs 单一来源 vs 竞争性谈判
- 合作模式：直接采购 vs 集成商采购
- 产品类型：标准产品 vs 定制开发
- 服务模式：本地部署 vs 云服务

**输出格式**：
```markdown
### 采购偏好

- **采购方式**：偏好公开招标/单一来源采购
- **合作模式**：倾向与系统集成商合作
- **产品类型**：需要定制化开发/接受标准产品
- **服务模式**：偏好本地部署/云服务
```

### 2. 采购周期分析

**分析维度**：
- 年度规律：固定月份采购
- 预算周期：财年/自然年
- 项目周期：规划/招标/实施周期

**输出格式**：
```markdown
### 采购周期

- **采购高峰期**：Q1/Q2/Q3/Q4
- **预算周期**：财年（X月-X月）
- **项目周期**：从规划到上线约X个月
```

### 3. 竞争对手分析

**分析维度**：
- 已中标厂商：WPS、Office、钉钉等
- 市场份额：各厂商中标次数、金额
- 产品覆盖：哪些产品线已被占领

**输出格式**：
```markdown
### 竞争对手

| 厂商 | 中标次数 | 主要产品 | 优势分析 |
|------|---------|---------|---------|
| WPS | X次 | WPS 365 | 本地化、国产化 |
| Office | X次 | Office 365 | 生态完善 |
| 钉钉 | X次 | 钉钉文档 | 免费策略 |
```

### 4. 市场切入点分析

**分析维度**：
- 未覆盖产品：哪些产品线尚未采购
- 替代机会：现有产品是否面临续约
- 差异化优势：WPS的独特价值

**输出格式**：
```markdown
### 市场切入点

- **未覆盖产品**：产品A、产品B
- **替代机会**：XX产品将于X年到期
- **差异化优势**：国产化、本地化、定制化
```
