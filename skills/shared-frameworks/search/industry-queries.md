## 使用示例

### 在Skill中使用

```markdown
# 教育行业客户深度研究

## 引用框架
@include shared-frameworks/search/baidu-web-search.md

## 客户基础搜索
# @baidu-search:background("{{customer_name}}", "education")
# @baidu-search:decision("{{customer_name}}", "education")
# @baidu-search:cooperation("{{customer_name}}")

## 行业热点搜索
# @baidu-search:industry-trend("教育信息化")

## 竞品分析
# @baidu-search:competitor("钉钉")
# @baidu-search:competitor("企业微信")

## 案例参考
# @baidu-search:case-study("高校智慧校园建设")

## 生成报告

基于搜索结果，生成包含以下内容的报告：

### 客户背景
@search-result:background

### 决策链分析
@search-result:decision

### 历史合作
@search-result:cooperation

### 行业热点分析
@search-result:industry-trend

### 竞品对比分析
@search-result:competitor

### 标杆案例参考
@search-result:case-study
```

### 动态参数

支持使用变量：

```markdown
# @baidu-search:industry-trend("{{industry}}信息化")
# @baidu-search:competitor("{{competitor_name}}")
# @baidu-search:case-study("{{customer_type}}{{project_type}}")
```
