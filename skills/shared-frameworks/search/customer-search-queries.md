## 教育行业

### 背景资料查询

```
{{customer_name}}的办学规模、学生人数、师资力量、办学特色等基本情况是什么？请用数字说话，包括具体的学生人数、教职工数量、校区分布等量化数据。另外，{{customer_name}}在教育信息化、数字化转型方面有哪些战略规划和建设重点？
```

**重点提取信息**：
- 学校类型（大学/高中/初中/小学/幼儿园/教育局）
- 学生人数、班级数量、教职工数量
- 办学层次、师资力量
- 数字化转型战略和规划
- 智慧校园建设重点

### 决策链查询

```
{{customer_name}}的校长、教务主任、信息化主任分别是哪些人？请重点搜索并总结他们关于教育信息化、数字化转型、智慧校园建设等方面的讲话、观点或相关政策。
```

**重点提取信息**：
- 高管层：校长/教育局局长
- 管理层：教务主任/信息化主任
- 采购层：采购负责人
- 关键决策人的数字化观点

### 历史合作查询

```
{{customer_name}}和金山办公WPS365在WPS 365、文档中心、文档中台、AI、云文档等方面有哪些合作项目、中标记录或签约情况？包括战略合作、联��研发、采购等形式。
```

**重点提取信息**：
- 合作产品（WPS Office / WPS 365 / 金山文档 / 金山协作）
- 合作范围（全校授权 / 特定院系 / 部门级 / 个人版）
- 合作时间（起始年份）
- 合作案例（具体项目名称）

### 数字化转型查询

```
{{customer_name}}在教育信息化、数字化转型、智慧校园建设方面有哪些战略规划、重点项目、建设动态？请重点搜索最近2-3年的政策和项目。
```

**重点提取信息**：
- 战略规划：总体目标、重点方向
- 重点项目：智慧校园、教学平台、数据中心

## 使用示例

### 在Skill中使用（基础版）

```markdown
# 教育行业客户深度研究

## 搜索配置

@include shared-frameworks/search/baidu-web-search.md

## 执行搜索

# @baidu-search:background("{{customer_name}}", "education")
# @baidu-search:decision("{{customer_name}}", "education")
# @baidu-search:cooperation("{{customer_name}}")

## 生成报告

基于以下搜索结果生成报告：

### 背景资料
@search-result:background

### 决策链
@search-result:decision

### 历史合作
@search-result:cooperation
```

```markdown
# 金融行业客户全方位研究

### 历史合作

@search-result:digital

### 招投标情况
@search-result:bidding

### 集团架构

### 年报/战略分析
@search-result:annual-report
```

### 动态参数

支持使用变量：

```markdown
# @baidu-search:background("{{customer_name}}", "{{industry}}")
# @baidu-search:decision("{{customer_name}}", "{{industry}}")
# @baidu-search:digital("{{customer_name}}", "{{industry}}")
```

行业参数会自动映射：
- `education` / `教育` → 教育行业查询
- `medical` / `医疗` → 医疗行业查询
- `government` / `政府` → 政府行业查询
- `enterprise` / `企业` → 企业行业查询
- `finance` / `金融` → 金融行业查询
